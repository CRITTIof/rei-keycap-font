Usage
  • font-size equals the visual key height; use line-height: 1.
  • Interior is transparent. Color the whole glyph with color / currentColor.
  • See MAPPING.md for the full event.code → codepoint table.
  • Normal text A-Z / a-z / 0-9 render the matching keycap glyph directly.
  • Letter and digit keycaps use a monospaced face, so every one has the same width.
  • 32 transparent icons: 8 software / file / AI (U+E100–U+E107), 9 hardware (U+E200–U+E208), 15 interface (U+E300–U+E30E).
  • Fn usually emits no browser key event; treat it as a custom/visual key.
